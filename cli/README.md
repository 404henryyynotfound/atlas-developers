# atlas-developers-cli

The zero-dependency command line tool for [Atlas Developers](https://github.com/404henryyynotfound/atlas-developers).

```bash
npm install -g atlas-developers-cli
atlas --version
atlas init
atlas ai insight
```

Data is stored locally in `~/.atlas-developers/`. Set `ATLAS_HOME` to override the location.

See the [main README](https://github.com/404henryyynotfound/atlas-developers#readme) for all commands.
